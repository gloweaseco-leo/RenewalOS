# RenewalOS — 体育培训续费机会引擎

独立于奥冠 `aoguan-webapp` 的早期产品原型，面向体育培训机构的**续费机会识别 → 人工跟进 → 成交记录 → 增量效果验证**闭环。

> **状态：MVP 0.1 / 本机原型 / 合成数据。** 不是可直接接入真实客户数据的生产级多租户SaaS。没有真实对照实验之前，不展示虚构的AI增量收益或ROI。

## 快速启动

需要 Python 3.10+。

```bash
python -m venv .venv
# macOS/Linux: source .venv/bin/activate
# Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python -m uvicorn renewalos.main:app --host 127.0.0.1 --port 8000
```

本机打开 http://127.0.0.1:8000 ，点击「载入合成数据」查看续费机会、对照组、规则组和AI组。默认**不接真实模型**，没有配置时不会伪造模型结果。

```bash
pip install -e '.[test]'
pytest -q
```

## 业务边界

- CSV导入：学员（代号/家庭ID/联系授权）、课包、出勤、续费与退款。金额按人民币元输入，内部按分保存。
- 机会识别：到期临近、剩余课时低、到课骤降，附可解释证据；不是未经训练的流失概率预测。
- 干预分组：按家庭稳定分配「正常运营对照 / 规则提醒 / AI辅助」，避免同一家庭不同学员串组。正常既有服务所有组继续提供。
- 人工执行：负责人、跟进状态和记录；不自动发消息或促销。
- 经营效果：只报告实际支付记录、家庭数与跟进数量；无成熟观察期、成本和基线时明确标为 `NOT_ESTABLISHED`，**不把自然续费算AI功劳**。
- 模型适配：可选 OpenAI-compatible HTTPS endpoint；仅发送去身份化的结构化信号，不包含学员名、手机号等身份信息。

## 非生产声明 / 安全

仅绑定 127.0.0.1 本地运行。当前没有账户登录、角色权限、加密备份、审计日志、企业数据隔离与数据删除策略，**禁止暴露公网、禁止导入真实未成年学员的可识别个人信息**。合成数据重置会清空本地数据库中的导入数据。示例仅用于技术与商业演示，未构成实际ROI或AI效果证据。

## 迭代关口

- **G0（本版本）**：独立演示闭环、规则证据、合成数据、三组实验框架、真实AI调用不可伪造。
- **G1**：取得商业授权、真实客户字段映射、权限/安全审计、脱敏和运营流程。
- **G2**：形成严谨的实验队列、固定口径的支付退款与履约成本、留存效果及不确定性报告，方可判断可复制经营价值。
