# RenewalOS MVP v0.1 — 产品边界与验收

**产品定义**：独立于奥冠 `aoguan-webapp` 的体育培训续费经营演示，支持 CSV 数据导入、续费机会识别、人工跟进及支付事实核验。

## 业务原则
- 机会不是成交，已付款不是AI增量，消课不是新增收入。
- 使用家庭级分组：正常运营（control）、规则辅助（rules）、AI辅助（ai）。所有组继续接受正常既有服务。
- 不具备实验成熟期、贡献毛利及成本证据时，增量利润、ROI必须显示不可计算，不能伪造。
- 默认仅规则建议；不配置真实API时不得显示伪AI生成内容。
- AI仅基于非识别化到期/课时/出勤信号给出建议，不编造流失原因。

## MVP功能
1. 标准CSV：learners / packages / attendance / renewals。
2. 可解释续费机会规则：到期、余课、出勤下降。
3. 家庭级持久化分组，防止建议串组。
4. 跟进记录、责任人、状态及结果。
5. 支付退款事实看板；不将相关性当因果性。
6. 可选 OpenAI-compatible HTTPS真实模型连接，只发送去身份化业务事实。

## 禁止事项
不得部署公网，不录入真实未成年人识别信息，不自动联系客户/承诺折扣，不直接集成奥冠未授权系统，不将本地SQLite原型当做生产SaaS。

## G1上线前提
合法数据使用授权、权限与账户、数据删除与审计、多租户隔离、导入映射、固定的权益续费周期、明确的实验观察期与统一成本口径。
